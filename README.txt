GRIDWAVE POWER CONSULTING LLC — COMPANY WEBSITE

Files
- index.html : complete website content and structure
- styles.css : responsive styling and visual system
- script.js  : mobile navigation, reveal animations, dynamic year

How to use
1. Upload the contents of this folder to any static web host.
2. Set index.html as the root/home page.
3. The site has no backend or build step.
